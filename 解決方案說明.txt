# FoodMAP 餐廳彈窗功能重構

## 問題描述

原有的餐廳彈窗功能存在以下問題：

1. 依賴 Google Places API，該 API 即將棄用，導致功能不穩定
2. 彈窗樣式不統一，存在多處重複代碼
3. 背景透明度不足，影響用戶體驗
4. 收藏按鈕和彈窗存在層級衝突
5. 點擊餐廳卡片時，營業時間按鈕會重複添加
6. 彈窗缺少地圖顯示功能，用戶無法直觀看到餐廳位置

## 解決方案

### 1. 創建新的彈窗 CSS

- 創建獨立的 `restaurant-modal-new.css` 文件，統一彈窗樣式
- 提高彈窗背景不透明度，從 0.7 提升至 0.85
- 提高彈窗 z-index 至 5000，確保在所有元素之上
- 優化彈窗動畫效果，使其更加流暢
- 更新彈窗樣式，使用橙色標題欄，與網站整體風格一致

### 2. 創建新的彈窗 JavaScript 模組

- 創建 `restaurant-modal.js` 模組，使用模組化設計
- 不再依賴 Google Places API，使用現有餐廳數據
- 統一處理營業時間顯示邏輯
- 優化收藏按鈕功能，確保與現有收藏系統兼容
- 添加地圖顯示功能，使用 Google Maps JavaScript API v3

### 3. 修改現有代碼

- 修改 `mapInit.js` 中的 `showRestaurantDetail` 方法，優先使用新彈窗
- 修改 `main.js` 中的彈窗相關代碼，兼容新舊彈窗
- 修復營業時間按鈕重複添加問題
- 調整收藏按鈕和彈窗的層級關係
- 添加地圖顯示區域，並確保地圖正確顯示餐廳位置

### 4. 兼容性處理

- 保留舊彈窗功能，確保向後兼容
- 在新彈窗不可用時自動回退到舊彈窗
- 統一事件處理邏輯，確保 ESC 鍵和點擊外部都能關閉彈窗
- 確保地圖功能在不同裝置上正常顯示

## 使用方法

新的彈窗功能已經與原有系統完全集成，無需額外操作即可使用。點擊任何餐廳卡片，都會自動使用新彈窗顯示餐廳詳情，並在下方顯示餐廳位置地圖。

## 技術細節

1. 新彈窗使用 CSS Grid 和 Flexbox 布局，確保響應式設計
2. 彈窗背景使用 rgba(0, 0, 0, 0.85) 提供更好的對比度
3. 使用 JavaScript 模組模式，避免全局變量污染
4. 新增臨時 ID 生成機制，解決部分餐廳缺少 ID 的問題
5. 優化圖片處理邏輯，支持多種圖片數據格式
6. 使用 Google Maps JavaScript API v3 顯示餐廳位置
7. 自定義地圖標記樣式，與網站整體風格一致

## 後續優化建議

1. 完全移除對 Google Places API 的依賴
2. 將所有餐廳數據存儲在本地數據庫中
3. 進一步優化彈窗動畫效果
4. 添加更多餐廳詳情，如菜單、評論等
5. 實現完全的離線功能
6. 添加路線規劃功能，直接在彈窗中顯示從用戶位置到餐廳的路線
